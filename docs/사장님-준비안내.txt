「정, 담따」 온라인 주문 - 준비 안내
====================================

앱은 완성되어 있습니다. 결제와 알림만 연결하면 문을 엽니다.
세 곳에 가입이 필요합니다.


■ 사장님이 직접 하셔야 하는 것 (세 가지뿐)
---------------------------------------------

나머지는 담당자가 대신 처리합니다.
다만 사장님 명의 휴대폰은 옆에 두셔야 합니다.

 1. 카카오 비즈니스 채널 사업자 인증
    - 사장님 카카오톡으로 전자증명서를 발급받아야 합니다

 2. 포트원 PG 계약서 서명 + 본인인증
    - 사업자 명의 계약이라 대리가 안 됩니다

 3. 보증보험 가입
    - PG 계약의 필수 조건입니다 (별도 비용)


■ 미리 준비해 주실 서류
------------------------

 [준비됨]    사업자등록증

 [진행 중]   통신판매업신고증
             → 포트원 심사에 필요합니다

 [준비 필요] 대표자 신분증
 [준비 필요] 통장 사본 (정산받을 계좌)

 [계속 사용] 사장님 명의 휴대폰 - 본인인증
 [계속 사용] 사장님 카카오톡 계정 - 채널 인증


■ 진행 순서
------------

< 지금 바로 시작 : 카카오 알림톡 (약 1~2주) >

주문이 들어오면 사장님 휴대폰으로 카톡이 오게 하는 작업입니다.

  1) 카카오 비즈니스 채널 만들기        - 담당자
  2) 채널 사업자 인증 신청              - 사장님 인증 필요
     (카카오 심사 3~7일)
  3) 솔라피 가입                        - 담당자
  4) 발신프로필 등록                    - 담당자
  5) 알림톡 문구 3종 등록 → 카카오 심사  - 담당자

  ※ 포트원과 상관없이 지금 시작할 수 있습니다.
     심사 기다리는 시간이 있어서 먼저 걸어 두는 게 좋습니다.


< 신고번호가 나온 뒤 : 결제 >

  6) 신고번호를 사이트에 반영            - 개발
  7) 실제 메뉴·사진으로 교체             - 개발
  8) 포트원 가입 + 전자결제 신청         - 담당자
  9) PG사 계약 + 보증보험                - 사장님
 10) 심사 (사이트를 직접 확인합니다)

  ※ 6, 7번을 먼저 하는 이유
     포트원 심사에서 실제 사이트를 봅니다. 신고번호가 비어 있거나
     임시 메뉴가 올라간 상태면 불리합니다.


■ 비용 안내
------------

< 알림톡 >

주문 한 건당 약 26원입니다.

  하루 20건  →  월 약 16,000원
  하루 30건  →  월 약 24,000원

주문 1건에 사장님께 1통, 손님께 1통 갑니다.
취소될 때만 손님께 1통 더 갑니다.

  ※ 단계마다(준비중·배달중·완료) 손님께 알리는 것도 가능하지만,
     비용이 2.5배가 되고 사장님이 주문마다 네 번씩 눌러야 해서
     빼기로 했습니다.

< 포트원·PG >

결제 수수료는 PG사와 계약할 때 정해집니다.
보증보험료가 별도로 듭니다.


■ 상담하실 때 이대로 말씀하세요
--------------------------------

< 솔라피 (알림톡 대행사) >

"동네 반찬가게 주문 알림입니다.
 주문 건당 매장 1통 + 손님 1통, 취소 시 1통 추가.
 하루 20~30건, 월 1,200~1,900통 예상.
 템플릿 3종. API 직접 연동합니다.
 SMS 대체발송은 빼 주세요."

  ※ SMS 대체발송은 알림톡이 실패했을 때 문자로 다시 보내는 옵션인데,
     문자가 3~4배 비쌉니다. 기본으로 켜 두는 곳이 많으니 꼭 말씀하세요.

  ※ 단가 외에 이 넷도 같이 물어보세요
     - 월 기본료
     - 최소 청구액
     - 선불(충전식)인지 후불인지
     - SMS 대체발송 요금

< 포트원 >

"간이과세자입니다"
  → 미리 말씀하시면 조건 확인이 빠릅니다.


■ 알림톡 문구 3종 (등록할 내용)
--------------------------------

앱이 보내는 문구와 한 글자라도 다르면 발송이 실패합니다.
아래 그대로 등록해 주세요.

  변수 표기 방식(#{...})은 대행사마다 다릅니다.
  솔라피 화면에 맞춰 조정하시고,
  승인된 최종 문구를 개발자에게 보내 주세요.


[1] 새 주문 - 매장이 받음

[정, 담따] 새 주문이 들어왔어요

주문번호: #{주문번호}
수령방법: #{수령방법}
주문금액: #{주문금액}
주문시각: #{주문시각}

#{상품요약}
#{수령정보}


[2] 주문 완료 - 손님이 받음

[정, 담따] 주문 완료

주문번호: #{주문번호}
#{안내문구}

  #{안내문구} 에 들어가는 두 가지
   - 배달일 때 : 주문이 접수됐어요. 준비되는 대로 배달해 드릴게요.
   - 픽업일 때 : 주문이 접수됐어요. 오후 3:30에 오시면 됩니다.


[3] 주문 취소 - 손님이 받음

[정, 담따] 주문 취소

주문번호: #{주문번호}
주문이 취소되었어요. 결제하신 금액은 환불됩니다.


■ 끝나면 개발자에게 전달할 값
------------------------------

이것만 주시면 그날 켜집니다. 앱을 다시 고칠 일은 없습니다.

< 포트원에서 받는 것 - 4개 >
  - 상점 ID
  - 채널 키
  - API 시크릿
  - 웹훅 시크릿

< 솔라피에서 받는 것 - 4개 >
  - API 주소
  - API 키
  - 발신프로필 키
  - 승인된 템플릿 코드

< 그 외 >
  - 통신판매업 신고번호
  - 승인된 알림톡 최종 문구
    (한 글자라도 다르면 발송이 실패해서 앱을 거기에 맞춰야 합니다)

  ※ API 시크릿, 웹훅 시크릿 같은 값은 비밀번호와 같습니다.
     단체 채팅방이나 메일에 올리지 마시고 개발자에게만 전달해 주세요.


■ 사장님이 지금 하실 일
------------------------

 1. 신분증 · 통장 사본 준비
 2. 카카오톡 로그인 확인 (채널 인증에 씁니다)
 3. 통신판매업 신고 결과 나오면 알려주기

나머지는 담당자가 진행하고,
인증·서명이 필요한 순간에만 말씀드립니다.


■ 함께 준비하면 좋은 것
------------------------

메뉴 정리 (엑셀 + 사진)

  신고번호가 나오는 대로 바로 교체할 수 있습니다.
  사진은 휴대폰으로 찍은 그대로 주셔도 앱이 알아서 줄이니
  크기는 신경 쓰지 않으셔도 됩니다.

  엑셀 양식은 docs/menu-template.csv 에 있습니다.
