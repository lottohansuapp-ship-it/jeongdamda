「정, 담따」 온라인 주문 - 준비 안내
====================================

앱은 어느정도 완성되었습니다. 결제와 알림만 연결하면 오픈 가능해요.
세 곳에 가입이 필요합니다.

사장님은 가입과 인증만 해 주시고,
계정 정보를 개발자에게 넘겨 주시면 나머지는 개발자가 진행합니다.


■ 사장님이 직접 하셔야 하는 것 (세 가지)
---------------------------------------------

아래 셋은 사장님 명의 확인이 필요해서 대신할 수 없습니다.
휴대폰을 옆에 두고 진행해 주세요.

 1. 카카오 비즈니스 채널 사업자 인증
    - 사장님 카카오톡으로 전자증명서를 발급받아야 합니다

 2. 포트원 PG 계약서 서명 + 본인인증
    - 사업자 명의 계약이라 대리가 안 됩니다

 3. 보증보험 - 전화 받고 동의 + 보험료 납부
    - PG사가 대신 신청합니다. 찾아가실 필요 없습니다
    - 필수는 아닙니다. 월 승인한도를 300만원 이하로 잡으면 면제됩니다
    - 한도를 넘어도 결제는 정상입니다.
      초과분 정산만 다음 회차로 밀립니다
    - 연 5~10만원 수준 (보증금액 × 약 0.953%, 1년치 선납)

 ※ 이 셋 말고는 개발자가 다 합니다.
    가입만 해 주시고 계정 정보를 넘겨 주시면 됩니다.


■ 계정 정보를 넘기실 때
------------------------

가입하신 뒤 아이디와 비밀번호를 개발자에게 알려 주세요.
그 계정으로 나머지 설정을 다 진행합니다.



■ 미리 준비해 주실 서류
------------------------

 [준비됨]    사업자등록증

 [진행 중]   통신판매업신고증
             → 포트원 심사에 필요합니다

 [준비 필요] 대표자 신분증
 [준비 필요] 통장 사본 (정산받을 계좌)

 [계속 사용] 사장님 명의 휴대폰 - 본인인증
 [계속 사용] 사장님 카카오톡 계정 - 채널 인증


■ 진행 순서
------------

< 지금 바로 시작 : 카카오 알림톡 (약 1~2주) >

주문이 들어오면 사장님 휴대폰으로 카톡이 오게 하는 작업입니다.

  1) 카카오 비즈니스 가입 + 채널 만들기  - 사장님 가입 → 개발자에게 전달
  2) 채널 사업자 인증 신청               - 사장님 (본인인증 필요)
     (카카오 심사 3~7일)
  3) 솔라피 가입                         - 사장님 가입 → 개발자에게 전달
                                           (요금이 청구되는 계정입니다)
  4) 발신프로필 등록                     - 개발자
  5) 알림톡 문구 3종 등록 → 카카오 심사   - 개발자

  ※ 포트원과 상관없이 지금 시작할 수 있습니다.
     심사 기다리는 시간이 있어서 먼저 걸어 두는 게 좋습니다.


< 신고번호가 나온 뒤 : 결제 >

  6) 신고번호를 사이트에 반영            - 개발자
  7) 실제 메뉴·사진으로 교체             - 개발자
  8) 포트원 가입 + 전자결제 신청         - 사장님 가입 → 개발자에게 전달
  9) PG사 계약 서명 + 보증보험           - 사장님 (본인인증 필요)
 10) 심사 (사이트를 직접 확인합니다)

  ※ 6, 7번을 먼저 하는 이유
     포트원 심사에서 실제 사이트를 봅니다. 신고번호가 비어 있거나
     임시 메뉴가 올라간 상태면 불리합니다.


■ 매달 나가는 돈
-----------------

< 서버 - 고정비 >

앱이 돌아가려면 두 곳이 필요합니다.

  Vercel    앱 화면을 띄우는 곳        월 20달러 (약 28,000원)
  Supabase  주문·회원 정보가 있는 곳    월 25달러 (약 35,000원)
                                       -----------------------
                                       합계 약 63,000원

  ※ 지금은 둘 다 무료 요금제입니다. 다만
     - Vercel 무료는 "개인·비상업용" 이라 장사에 쓰면 약관에 어긋납니다
     - Supabase 무료는 일주일간 접속이 없으면 프로젝트가 멈춥니다
       (손님이 없는 주가 있으면 앱이 죽어 있을 수 있습니다)

     결제를 켜기 전에 유료로 올리는 것이 안전합니다.
     현재 요금제는 개발자가 확인해서 알려드립니다.

  ※ 사용량이 많아지면 위 금액을 넘을 수 있습니다.
     동네 반찬가게 규모에서는 기본 요금 안에서 끝날 가능성이 큽니다.


< 알림톡 - 주문한 만큼 >

주문 한 건당 약 26원입니다. (솔라피에 냅니다)

  하루 20건  →  월 약 16,000원
  하루 30건  →  월 약 24,000원

주문 1건에 사장님께 1통, 손님께 1통 갑니다.
취소될 때만 손님께 1통 더 갑니다.

  ※ 단계마다(준비중·배달중·완료) 손님께 알리는 것도 가능하지만,
     비용이 2.5배가 되고 사장님이 주문마다 눌러야 해서
     우선 프로그램 코드는 진행하지 않았습니다.


< 합계 >

  서버       약 63,000원
  알림톡    약 16,000원  (하루 20건 기준)
            ---------------------------
            월 약 79,000원

  하루 30건이면 월 약 87,000원


< 파는 만큼 나가는 돈 >

  결제 수수료   매출의 몇 % - PG사와 계약할 때 정해집니다
  보증보험료    연 5~10만원 - 드는 경우에만 (위 참고)

  ※ 포트원 자체 이용료가 따로 있는지는 상담할 때 확인해 주세요.


■ 상담하실 때 이대로 말씀하세요
--------------------------------

< 솔라피 (알림톡 대행사) >

"동네 반찬가게 주문 알림입니다.
 주문 건당 매장 1통 + 손님 1통, 취소 시 1통 추가.
 하루 20~30건, 월 1,200~1,900통 예상.
 템플릿 3종. API 직접 연동합니다.
 SMS 대체발송은 빼 주세요."

  ※ SMS 대체발송은 알림톡이 실패했을 때 문자로 다시 보내는 옵션인데,
     문자가 3~4배 비쌉니다. 기본으로 켜 두는 곳이 많으니 꼭 말씀하세요.

  ※ 단가 외에 이 넷도 같이 물어보세요
     - 월 기본료
     - 최소 청구액
     - 선불(충전식)인지 후불인지
     - SMS 대체발송 요금

< 포트원 >

"간이과세자입니다"
  → 미리 말씀하시면 조건 확인이 빠릅니다.

  ※ 보증보험 관련해서 이 셋도 물어보세요
     - 월 승인한도를 얼마로 잡을 수 있나요?
     - 한도를 넘으면 정산이 얼마나 밀리나요?
     - 정산 주기는 어떻게 되나요? (주 1회 / 월 2회 등)

  ※ 포트원 이용료가 따로 있는지도 확인해 주세요.


■ 알림톡 문구 3종
------------------

등록은 개발자가 합니다.
다만 심사 과정에서 문구가 바뀔 수 있어 적어 둡니다.
앱이 보내는 문구와 한 글자라도 다르면 발송이 실패합니다.


[1] 새 주문 - 매장이 받음

[정, 담따] 새 주문이 들어왔어요

주문번호: #{주문번호}
수령방법: #{수령방법}
주문금액: #{주문금액}
주문시각: #{주문시각}

#{상품요약}
#{수령정보}


[2] 주문 완료 - 손님이 받음

[정, 담따] 주문 완료

주문번호: #{주문번호}
#{안내문구}

  #{안내문구} 에 들어가는 두 가지
   - 배달일 때 : 주문이 접수됐어요. 준비되는 대로 배달해 드릴게요.
   - 픽업일 때 : 주문이 접수됐어요. 오후 3:30에 오시면 됩니다.


[3] 주문 취소 - 손님이 받음

[정, 담따] 주문 취소

주문번호: #{주문번호}
주문이 취소되었어요. 결제하신 금액은 환불됩니다.

------------------------

 4. 카카오 비즈니스 · 솔라피 가입 후 계정 정보 전달

본인인증·서명이 필요한 순간에만 말씀드립니다.


■ 함께 준비하면 좋은 것
------------------------

메뉴 정리 (엑셀 / 사진 + 메뉴 간단 설명)

  신고번호가 나오는 대로 바로 교체할 수 있습니다.
